==================================================================================================

STEVEN — PERSONAL PORTFOLIO

==================================================================================================


DESCRIPTION:

This is the personal portfolio website of Steven (Gerardo Aramis Cabello Acosta), a Fullstack
Software Developer specializing in Web and Mobile Development with experience in Cloud Computing.

The site showcases professional experience, technical skills, education, certifications, and a
curated selection of projects spanning mobile apps, web applications, and landing pages.


SECTIONS:

  - Intro: Animated hero section with an interactive particle constellation canvas and
    gradient shimmer text.

  - About: A summary of Steven's background, expertise areas (Frontend, Backend, Mobile
    Development, Cloud Computing, DevOps, Database Management), and an animated tech stack
    marquee featuring 25+ technologies.

  - Experience: A timeline of professional roles at PepsiCo International, Elife, Secretaria
    de Hacienda y Crédito Público (SHCP), Paquete.MX, MBR Hosting, and Samsung NIESA. Each
    entry includes a description and relevant technology chips.

  - Education: Academic background including Computer Systems Engineering at ESCOM (IPN),
    DBA OCA 12 certification, and Scrum Fundamentals certification.

  - Projects: A gallery of featured projects including Joy App, Fest, Investus, goelU,
    Solutions Cargo, Paquete.MX, Typhoon Offshore, Al Alza, CotiSAP, Perfilador BBVA,
    Simulador BBVA, and more.

  - Contact: A section with email and social links.


FEATURES:

  - Interactive particle constellation background (mouse-reactive)
  - Animated gradient shimmer text on hero title
  - 3D tilt effect on project cards with shine overlay
  - Custom animated cursor with hover effects
  - Magnetic buttons
  - Tech stack marquee with dual-row infinite scroll
  - Scroll-triggered text reveal animations
  - Animated section dividers
  - Expandable experience timeline (View More / View Less)
  - Responsive design for all screen sizes
  - Downloadable CV


TECH STACK:

  - HTML5
  - CSS3 (custom properties, animations, glassmorphism)
  - Vanilla JavaScript
  - Anime.js (animations)
  - Swiper (carousel/slider)
  - MoveTo.js (smooth scrolling)
  - Basic Lightbox (image modals)
  - Font Awesome (icons)


PROJECT STRUCTURE:

  index.html          Main page
  css/
    styles.css        Custom styles and design system
    vendor.css        Third-party CSS (normalize, grid, etc.)
  js/
    main.js           Core JavaScript functionality
    plugins.js        Third-party JS libraries (bundled)
  images/             Avatar, portfolio screenshots, and project assets
  icons/              Technology and service icons
  cv/                 Downloadable CV (PDF)


ORIGINAL TEMPLATE:

This project was initially scaffolded from the "Luther" template by Styleshout
(https://www.styleshout.com). It has since been heavily customized with new sections,
interactive features, and a complete content overhaul to serve as a personal portfolio.
